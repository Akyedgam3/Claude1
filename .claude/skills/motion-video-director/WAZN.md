# وزن — ملحق «مخرج الفيديو» (اقرأه مع SKILL.md قبل أي فيديو لوزن)

هاد الملحق بيكيّف SKILL.md على مشروع وزن وعلى بيئة Claude Code بالسحابة. إذا تعارض شي هون مع SKILL.md، **الملحق هو اللي بيمشي**.

## البيئة (سحابة، مش جهاز صاحب المشروع)
- منشتغل بحاوية سحابية مؤقتة، مش على PC صاحب المشروع. «مجلد المشروع» = `marketing/video/<اسم-الفيديو>/` بالمستودع، والملفات الكبيرة (فريمات، رندرات، cache) بمجلد الـ scratchpad مش بـ git.
- **مفاتيح الـ API:** ما في `.env` يدوي. أي مفتاح (Pexels، Pixabay، Freesound، ElevenLabs، Firecrawl) بينطلب بأداة `request_credential` (نافذة آمنة، البروكسي بيحقنه بالطلبات). ما منطبع ولا منحفظ ولا منعمل commit لأي مفتاح.
- الشبكة: أي موقع محجوب بيبان كـ 403 من البروكسي ← `get_environment` ثم اقتراح إضافته (`update_environment`). Hugging Face مسموح (لـ faster-whisper).
- **PROGRESS.md و LOG.md و manifest.json** جوّا مجلد الفيديو بالمستودع (صغار)، ومنعمل commit مع كل مرحلة.

## دروس من فيديوهات سابقة (مهم)
1. **الصوت هو الساعة:** دايماً فرّغ تسجيل صاحب المشروع بـ faster-whisper وركّب كل مشهد على كلمته. مرة ركّبنا على نص مفترض وطلع الفيديو «بعيد جداً عن الصوت» — ممنوع نخمّن النص.
2. **ما منبني ولا منرندر قبل الموافقة:** ابعت 6–8 صور ثابتة (contact sheet) أول، واستنى «تمام». صاحب المشروع وقّف رندر كامل بعد ما شاف الصور («ما بدي الفيديو هيك») — الصور هي بوابة القرار.
3. **أسلوب «أكشن موشن» (ألوان بتنقلب كل قطعة + كلمة ضخمة بكل بيت) ما عجبه** بالشكل اللي انعمل. قبل أي فيديو اسأل عن مرجع (رابط فيديو عجبه) وطابقه (§13)، وما تفترض الأسلوب.
4. بدّو شي **«احترافي أسطوري وما يبان إنو معمول بالـ AI/الكود»**: الحل لقطات حقيقية (تصوير محلات، Pexels)، صوت بشري، تدرّج لوني واحد، حركة مدروسة مش كثيرة، ومؤثرات صوتية موزونة. الكود للـ UI والنصوص بس.
5. شاشات البرنامج **حقيقية دايماً** (Playwright)، ما منرسمها بالـ AI لأنو بيخترع أزرار.
6. «الدفتر» كصورة للفوضى انتقده — استعمل رموز أقوى (إيصالات، أوراق، أرقام حمرا).
7. الكلمات لازم توسع بالمنطقة الآمنة (عمودي: x 140–940، y 230–1480): قيس العرض وصغّر الخط تلقائياً.
8. **ad-pro «بلا نظام» (8/11/2026) انلغى بعد الصور الثابتة** («ما عجبني»): بطاقات زجاج رمادية + نص كبير + أجهزة مرسومة بالكود على خلفية سادة. يعني حتى الأسلوب الهادي «المرسوم بالكود» ما بيكفي — المرة الجاية اطلب مرجع بصري منه قبل أي شغل، وفكّر بلقطات حقيقية/AI سينمائية بدل واجهات مرسومة.
9. التوصيل: MP4 تحت 30MB، H.264 yuv420p، AAC، faststart، −14 LUFS؛ وتبعت وصف للنشر (إنستا/فيس/شورتس) إذا طلب.

## خطوات أي فيديو جديد لوزن
1. رسالة البداية (§0a) مختصرة بالسوري: شو بدي منك (مرجع + القصة + المدة + الشكل).
2. إذا ما في تسجيل: اكتب نص صوت (§10a) جاهز لـ ElevenLabs **أو** ليسجّله صاحب المشروع بصوته، باللهجة السورية.
3. بعد ما يوصل الـ MP3: تفريغ بوقت الكلمات ← `beats.json` ← ستوري بورد ← **صور ثابتة للموافقة**.
4. بعد «تمام»: المشاهد + الموسيقى + المعاينات ← **موافقة** ← الرندر النهائي ← QA (§15) ← تسليم + commit.
