# مفاتيح التطوير

`license-private.dev.pem` مفتاح **للتطوير والتجربة فقط**، وهو منشور في المستودع فلا يحمي أي شيء.

قبل توزيع البرنامج تجارياً:

```bash
npm run license:keygen   # يولّد keys/license-private.pem (احفظه بأمان) ويحدّث src/license/public-key.ts
```

بعدها كل التراخيص المصدرة بمفتاح التطوير تصبح غير صالحة في النسخة التجارية.
