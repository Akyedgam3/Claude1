# ميزان — نظام محاسبة لكل المصالح والتجارات في سوريا

برنامج محاسبة لسطح المكتب (ويندوز 10 وما فوق) يعمل **بدون إنترنت**، وبياناته **مشفّرة على جهاز المستخدم** بدون أي قاعدة بيانات.
العملات: **الليرة السورية الجديدة والدولار الأمريكي** فقط.

| النشاط | الميزات الخاصة |
|--------|----------------|

## ما يشمله البرنامج

- **المحاسبة:** قيد مزدوج، دليل حسابات شجري، قيود يدوية، إقفال الفترات والسنة المالية، أرصدة افتتاحية.
- **البيع والشراء:** فواتير ومرتجعات، نقطة بيع سريعة، خصومات، ضريبة الإنفاق الاستهلاكي، حد الدين للعملاء، البيع بالليرة أو الدولار.
- **المخزون:** مستودعات متعددة، تكلفة وسطية، جرد، تالف، تحويل، دفعات وصلاحية، أرقام تسلسلية، وحدات متعددة، إنتاج.
- **التقارير:** الأرباح والخسائر، الميزانية، حركة الصناديق، أرباح المواد، المبيعات حسب البائع، أعمار الديون، المخزون، كشوف الحساب، ميزان المراجعة.
- **الفواتير:** 3 تصاميم (عصري بلون شركتك، كلاسيكي، بسيط)، رمز QR، ختم مدفوعة/آجل/ملغاة، خانات توقيع، شروط وأحكام، مع معاينة مباشرة في الإعدادات. نسخ الفاتورة كنص لإرسالها على واتساب.
- **عروض الأسعار:** عرض سعر يُطبع للزبون ولا يمس المخزون، ويتحول لفاتورة بكبسة زر.
- **إغلاق اليوم:** تقرير آخر الدوام لكل موظف أو للمحل كله: المبيعات، النقد، الدين، المرتجعات، السندات، والأكثر مبيعاً. يُطبع على الطابعة الحرارية.
- **الوضع الداكن،** وتذكير الزبون بدينه برسالة جاهزة.
- **الطباعة والتصدير:** A4 وA5 وحراري 80mm و58mm، الشعار، التفقيط، المقابل بالدولار، طابعة لكل نوع مستند، ملصقات باركود، **PDF وExcel وCSV**، استيراد المواد من Excel.
- **المستخدمون:** 7 أدوار و27 صلاحية قابلة للتخصيص، وكل عملية تُسجَّل باسم من نفّذها.
- **سهولة الاستخدام:** بحث سريع في كل البرنامج (Ctrl+K)، ومفاتيح سريعة: F2 فاتورة مبيع، F3 نقطة البيع، F4 فاتورة شراء، F6 المواد، F7 العملاء، F8 التقارير.
- **أكثر من جهاز:** جهاز رئيسي وأجهزة فرعية على الشبكة المحلية بدون إنترنت.

## الحماية

| الطبقة | ما تفعله |
|--------|----------|
| تشفير البيانات | كل عملية مشفّرة بـ AES-256-GCM. مفتاح البيانات محفوظ مغلّفاً بكلمة سر كل مستخدم (scrypt) وبرمز استرداد |
| سجل لا يُعدَّل | كل عملية مربوطة بالتي قبلها، وأي تعديل أو حذف في الملف يُكتشف عند الفتح |
| الصلاحيات | تُفحص في العملية الرئيسية قبل تنفيذ أي عملية، وليس في الواجهة فقط |
| الشبكة المحلية | رسائل مشفّرة برمز الربط، مع منع إعادة الإرسال |
| البرنامج نفسه | الواجهة معزولة (sandbox)، أدوات المطوّر مغلقة، التنقل ممنوع، Electron Fuses مفعّلة، والكود مضغوط |
| الترخيص | توقيع Ed25519، مربوط ببصمة الجهاز، كشف إرجاع الساعة، وإيقاف عن بعد |

> **ملاحظة صادقة:** لا توجد حماية برمجية على جهاز العميل لا يمكن كسرها نهائياً. هذه الطبقات تجعل الكسر صعباً جداً على المستخدم العادي، والإيقاف عن بعد يعمل طالما يتصل البرنامج بالإنترنت من وقت لآخر.

## البيع والتراخيص (لك كبائع)

### 1. قبل أول بيع (مرة واحدة فقط)
```bash
npm run license:keygen
```
- يولّد `keys/license-private.pem`. **احفظه بمكان آمن جداً، فبدونه لا تستطيع إصدار تراخيص.**
- يحدّث المفتاح العام داخل البرنامج. بعدها أعد بناء ملف التنصيب.

### 2. رابط "قائمة الحالة" (للإيقاف عن بعد)
- ضع رابطاً عاماً في `src/license/config.ts` داخل `LICENSE_FEED_URLS`. يمكن أن يكون من GitHub Pages أو Cloudflare Pages أو موقعك الخاص، ويمكن وضع أكثر من رابط احتياطاً.
- البرنامج يتحقق من هذا الرابط عند التشغيل وكل 3 ساعات.

### 3. لوحة الإدارة
**على ويندوز:** دبل كليك على `Mizan-Admin.cmd`، فبيثبّت الحزم أول مرة لحالو وبيفتح اللوحة بالمتصفح. لازم يكون Node.js منصّب، ومجلد `keys` الأصلي منسوخ جوا مجلد المشروع (الملف بيرفض يشتغل بدونه).

أو من الطرفية:
```bash
npm run admin
```
افتح الرابط الظاهر (`http://127.0.0.1:4100`). من هذه اللوحة تستطيع:
- **إضافة عميل:** الاسم، وبصمة جهازه (تظهر له في شاشة التفعيل)، ونوع الاشتراك (شهري، 3 أشهر، 6 أشهر، سنوي، أو دائم)، وعدد الأجهزة، وأيام العمل بدون إنترنت.
- **تمديد** الاشتراك، أو **إيقافه مؤقتاً** مع رسالة تظهر للعميل، أو **إلغاؤه نهائياً**، أو **نقله لجهاز جديد**.
- **نشر قائمة الحالة:** يكتب الملف `keys/feed.txt`، فترفعه إلى الرابط.

### كيف يعمل الإيقاف
- **بدون ترخيص:** البرنامج لا يفتح أبداً، وتظهر شاشة التفعيل فقط.
- **عند الإيقاف من اللوحة ونشر القائمة:** البرنامج يغلق نفسه عند أول تحقق، أي خلال 3 ساعات كحد أقصى إن كان متصلاً بالإنترنت.
- **إن قطع العميل الإنترنت:** يعمل البرنامج عدد الأيام المحدد في ترخيصه (7 افتراضياً)، ثم يتوقف حتى يتصل.
- **انتهاء الاشتراك:** البرنامج يتوقف.
- **عميل بدون إنترنت أبداً:** مدّد له في اللوحة، ثم أرسل له **المفتاح الجديد** ليلصقه.

## التشغيل والبناء

```bash
npm install
npm run dev          # تشغيل للتطوير
npm run build        # بناء البرنامج
npm run dist:win     # ملف التنصيب لويندوز (يُبنى تلقائياً على GitHub أيضاً)
```

- **ملف التنصيب:** يُبنى تلقائياً مع كل تعديل في GitHub. من تبويب **Actions** اختر **Build Windows installer** ثم **Mizan-Windows**.
- **مكان البيانات:** بيانات كل شركة في `المستندات\Mizan\<اسم الشركة>`.

## الاختبارات

```bash
npm test             # اختبارات الوحدات
npm run typecheck    # فحص الأنواع
npm run build && npm run test:e2e   # اختبارات الواجهة الكاملة على البرنامج الحقيقي
```

| النوع | العدد | يغطي |
|-------|-------|------|
| اختبارات الوحدات | 77 | المحاسبة، المخزون، الأنشطة، التشفير، التراخيص، الصلاحيات، الشبكة |
| اختبارات الواجهة (Playwright + Electron) | 7 | انظر القائمة تحتها |

اختبارات الواجهة تمرّ على:
- الترخيص والإيقاف عن بعد.
- ورشة سيارات كاملة.
- سوبرماركت بباركود الميزان.
- صيدلية بالدفعات.
- مطعم بالوصفات.
- صلاحيات الكاشير.
- جهازان على الشبكة.

## البنية

```
src/core/      المنطق المحاسبي والأنشطة (بدون أي اعتماد على النظام)
src/storage/   حفظ الشركة مشفّرة على الجهاز
src/license/   الترخيص وقائمة الحالة
src/app/       تنفيذ العمليات بالصلاحيات + الشبكة المحلية
src/main/      Electron: النوافذ، الملفات، الطباعة، التصدير
src/preload/   الجسر الآمن للواجهة
src/renderer/  الواجهة (React، عربية)
admin/         لوحة إدارة التراخيص (لك فقط)
tests/         اختبارات الوحدات و tests/e2e اختبارات الواجهة
```
