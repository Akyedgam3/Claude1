# ميزان — نظام محاسبة سوري لسطح المكتب

برنامج محاسبة يعمل بدون إنترنت، وتُحفظ بياناته على جهاز المستخدم نفسه (بدون قاعدة بيانات).
الخطة الكاملة في [docs/PLAN.md](docs/PLAN.md).

## البنية

```
src/core/      المنطق المحاسبي (حسابات، قيود، عملات، ضرائب، تقارير) — لا يعتمد على الواجهة ولا على الحفظ
src/storage/   حفظ الشركة كمجلد على الجهاز: سجل عمليات + لقطة + نسخ احتياطية
src/license/   التحقق من الترخيص بدون إنترنت
scripts/       أدوات إصدار التراخيص (للاستخدام الداخلي فقط)
tests/         الاختبارات
```

## الأوامر

```bash
npm install
npm test            # الاختبارات
npm run typecheck   # فحص الأنواع
npm run license:keygen                      # مرة واحدة: توليد مفاتيح التوقيع
npm run license:issue -- --customer "الاسم" --machine XXXX-XXXX-XXXX-XXXX --plan annual
```

خطط الاشتراك: `monthly`, `quarterly`, `semiannual`, `annual`, `lifetime`.

> مجلد `keys/` يحتوي المفتاح الخاص لإصدار التراخيص، وهو مستثنى من git. احفظ نسخة منه بمكان آمن؛
> فقدانه يعني عدم القدرة على إصدار تراخيص للنسخ الموزّعة.
