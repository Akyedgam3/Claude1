# ميزان — خطة نظام المحاسبة السوري

> الحالة: القرارات الأساسية اعتُمدت (القسم 6). المرحلة 0 قيد التنفيذ.

## 1. الفكرة

برنامج محاسبة لسطح المكتب يعمل **بالكامل بدون إنترنت**، وتُحفظ بياناته **على جهاز المستخدم نفسه**،
ويصلح لأي نوع من المصالح: محل مفرق، تاجر جملة، مستودع، صيدلية، مطعم، ورشة، مكتب خدمات، شركة صغيرة.

الفكرة الأساسية: **نواة محاسبية واحدة (قيد مزدوج)** وفوقها **وحدات** يفعّلها المستخدم حسب نوع مصلحته.
أي عملية (فاتورة، سند، مرتجع، رواتب...) تولّد قيداً محاسبياً تلقائياً، فتبقى التقارير المالية صحيحة دائماً.

## 2. ما يميّزه للسوق السوري

- **تعدد العملات من الأساس**: ليرة سورية (القديمة والجديدة بعد حذف الصفرين)، دولار، ليرة تركية، يورو...
  - نشرة أسعار صرف يومية يدخلها المستخدم (أو أكثر من سعر: رسمي / سوق).
  - كل حركة تُحفظ بعملتها وبسعر الصرف وقتها، وتُعرض التقارير بأي عملة.
  - حساب فروقات الصرف (ربح/خسارة).
  - أداة تحويل الأرصدة بين الليرة القديمة والجديدة.
- **دليل حسابات جاهز** مبني على النظام المحاسبي الموحد السوري، مع قوالب جاهزة لكل نوع نشاط.
- **عربي بالكامل (RTL)**، مع إمكانية إضافة الإنكليزية لاحقاً.
- **يعمل على أجهزة ضعيفة** وبدون إنترنت، والتفعيل (الترخيص) يتم بدون إنترنت.
- **طباعة على الطابعات الحرارية** (80mm / 58mm) وعلى A4، مع باركود.
- **الديون والذمم**: كشوف حساب، أعمار الديون، تقسيط، شيكات وكمبيالات.

## 4. التقنية المقترحة

| الجزء | المقترح | السبب |
|-------|---------|-------|
| الواجهة | React + TypeScript | واجهات عربية حديثة وسهلة التطوير |
| غلاف سطح المكتب | Electron | ويندوز 10 وما فوق، ويطبع بسهولة على الحرارية وA4 |
| الحفظ | **ملف واحد على جهاز المستخدم** لكل شركة (مثلاً `شركتي.acc`) | لا خادم ولا تنصيب قاعدة بيانات |
| صيغة الملف | **بدون قاعدة بيانات**: سجل عمليات نصي (سطر لكل عملية) لا يُعدَّل، مع سلسلة بصمات تكشف أي عبث، ولقطة لتسريع الفتح | تحمّل انقطاع الكهرباء، وأثر كامل لكل عملية |
| النسخ الاحتياطي | نسخ تلقائي يومي إلى مجلد / فلاشة، مع الاحتفاظ بآخر N نسخة | حماية من انقطاع الكهرباء وتعطل الأقراص |
| الحسابات المالية | أعداد صحيحة/عشرية دقيقة (بدون أخطاء الفاصلة العائمة) | دقة المبالغ الكبيرة بالليرة |

### بنية المشروع المقترحة

```
apps/desktop/        ← غلاف Electron (النوافذ، الطباعة، الوصول للملفات)
packages/core/       ← المنطق المحاسبي (القيود، الأرصدة، العملات) + اختبارات
packages/storage/    ← طبقة الحفظ على الملف المحلي + النسخ الاحتياطي
packages/ui/         ← شاشات React
templates/           ← أدلة الحسابات الجاهزة حسب النشاط
```

فصل **المنطق المحاسبي** عن الواجهة وعن الحفظ يعني أننا نستطيع لاحقاً عمل نسخة موبايل
أو مزامنة بين أجهزة دون إعادة كتابة النواة.

## 5. مراحل التنفيذ

1. **المرحلة 0 – الأساس**: هيكل المشروع، الحفظ على الملف، إنشاء/فتح شركة، دليل الحسابات، القيد اليومي، العملات وأسعار الصرف، ميزان المراجعة.
2. **المرحلة 1 – التشغيل اليومي**: الصندوق وسندات القبض والدفع، العملاء والموردون وكشوف الحساب.
3. **المرحلة 2 – التجارة**: المواد والمستودعات، فواتير المبيعات والمشتريات والمرتجعات، الطباعة.
4. **المرحلة 3 – التقارير**: قائمة الدخل، الميزانية، أرباح المواد، التصدير إلى Excel وPDF.
5. **المرحلة 4 – نقطة البيع**: شاشة كاشير سريعة وطابعة حرارية وباركود.
6. **المرحلة 5 – الأمان والتوزيع**: المستخدمون والصلاحيات، تشفير الملف، الترخيص، برنامج التنصيب.
7. **لاحقاً**: الرواتب، التصنيع البسيط، العمل على أكثر من جهاز في الشبكة المحلية، نسخة موبايل.

## 6. القرارات المعتمدة

| الموضوع | القرار |
|---------|--------|
| الاسم | **ميزان** (Mizan) |
| نظام التشغيل | ويندوز 10 وما فوق |
| الحفظ | على جهاز المستخدم نفسه، بدون قاعدة بيانات ولا خادم. كل شركة مجلد فيه سجل العمليات والنسخ الاحتياطية |
| عدد الأجهزة | أكثر من جهاز ممكن: البيانات تبقى على **الجهاز الرئيسي**، والأجهزة الأخرى (كاشير ثانٍ مثلاً) تتصل به عبر الشبكة المحلية بدون إنترنت |
| الضرائب | ضريبة الإنفاق الاستهلاكي ورسوم أخرى، بنسب يحددها المستخدم (تختلف حسب السلعة والنشاط) |
| الطباعة | أساسية: طابعات حرارية 80/58mm وA4، مع باركود |
| البيع | اشتراك شهري / 3 أشهر / 6 أشهر / سنوي / شراء دائم |

### الترخيص (بدون إنترنت)
- المستخدم يرسل لنا **بصمة جهازه** (تظهر في البرنامج).
- نصدر له **مفتاح ترخيص موقّع** (Ed25519) يحدد: الجهاز، نوع الاشتراك، تاريخ الانتهاء، عدد الأجهزة.
- البرنامج يتحقق من التوقيع بمفتاح عام مضمّن فيه، فلا يمكن تزوير المفتاح أو تعديل مدته.
- كشف إرجاع ساعة الجهاز للخلف.
- عند انتهاء الاشتراك: البرنامج يفتح **للقراءة والطباعة فقط** حتى التجديد (لا تضيع بيانات الزبون).
